## 고유 H (원인 기준)

1. **위험 환자가 아무에게도 알려지지 않는 경로가 다수다**(횡단 H-1~H-4, survey H): 위험 신호 입력원이 배포에 없음(G01), 저작되는 `risk_phrases` 등을 survey 코드가 참조하지 않음, 위험 정지가 성공(DELIVERED)하면 키오스크가 대기 화면으로 가지 않고 "말씀해 주세요"에 머묾(실서버 조합 시험 없음), 규칙 감지가 추출 성공 뒤에만 돌아 모델 장애 때 놓침, 쓰기 확정 실패·턴 마감 초과 때 알림 없음. → **도메인 결정 + 일부 자율 수정**.
2. **개인정보 보존이 모든 곳에서 기본 무기한이다**(횡단 H-5, ops-feedback H, survey, outbox DEAD, 백업). 삭제 경로도 일부 없다. → **보존 기간은 사용자 결정, 삭제 기능은 자율**.
3. **평문 전송(TLS 없음)**(deploy H, 횡단 H-6). 지금은 127.0.0.1 바인드라 노출 없음. → **도메인·인증서는 사용자 결정**.
4. **백업이 동작하지 않는다**(deploy H). 설정 없음, 암호화·복원 시험·시점 일관성 없음. → **O16 결정 + 자율 구현**.
5. **이전 환자의 `subject_ref`로 새 환자 세션이 시작될 수 있다**(kiosk H). → **자율 수정, 접수 연동 방식은 사용자 확인**.
6. **환자 음성이 브라우저 STT 제공자(Google 등)로 나간다**(kiosk H). → **사용자 결정**.
7. **텍스트 양식 추출기 입력 크기 제곱 시간 → 서비스 정지**(question-authoring H). → **자율 수정**.
