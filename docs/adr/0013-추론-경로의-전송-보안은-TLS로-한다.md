# 0013. 추론 경로의 전송 보안은 TLS로 한다(WireGuard/Tailscale은 보안 경계로 삼지 않는다)

- 상태: **채택(2026-10-29, 사용자 결정)**. 구현은 아직 하지 않았다.
- 관련: D72(외부 추론 서버 모드), D84·ADR 0006(비밀은 파일로), ADR 0012·D113(키오스크 mTLS), D114

## 맥락

- survey-service는 추론 서버(I9)를 HTTP로 부른다. D72로 추론 서버를 다른 기계(GPU 서버)에 둘 수 있다(`deploy/scripts/up.sh --external-inference <URL>`). 그 경우 요청은 네트워크를 건너고, 요청 본문에는 환자 발화가 들어 있다.
- 지금 외부 추론 모드의 시험은 같은 호스트 안(`host.docker.internal`)에서만 했다. 기계 사이를 건너는 호출의 전송 보호 방식은 정해져 있지 않았다. 지금 경로가 평문 HTTP인지는 이 ADR을 쓸 때 코드로 확인하지 않았다(미확인).
- 개발 중에는 임대 서버와 GPU PC를 Tailscale(WireGuard)로 묶어 시험할 계획이다. tailnet 안의 트래픽은 암호화되고 시험 데이터는 합성 데이터뿐이다. 그래서 **개발 중** 평문 HTTP의 유출 위험은 낮다. 이 판단은 개발 기간에만 쓴다. 운영 방식은 따로 골라야 했다.

## 결정

1. 운영에서 추론 경로(survey-service → 추론 서버)는 **TLS(HTTPS)**로 보호한다. 클라이언트는 서버 인증서를 조직 CA로 검증한다.
2. 호출자 확인은 지금처럼 토큰으로 한다(D84, 파일로 받음). 호출자 인증서(mTLS)는 쓰지 않는다. 추론 서버를 부르는 곳이 survey-service 하나뿐이라, 토큰을 인증서로 바꿔서 얻는 이득이 적다.
3. TLS를 끝내는(종단) 곳은 추론 서버 앞의 Caddy다. 게이트웨이와 같은 도구를 쓴다.
4. WireGuard/Tailscale은 개발 연결과 운영 관리 접속용으로만 쓴다. 이 보안 결정은 그것에 기대지 않는다.

## 왜

- **표준:** HTTP API의 전송 보호는 TLS가 표준이다. 클라이언트도 이미 `https://` 주소를 받는다(`deploy/scripts/lib.sh`의 외부 추론 주소 검사).
- **운영 방식 하나:** 키오스크 기기 인증이 이미 TLS(mTLS, ADR 0012)다. 인증서 발급·폐기를 조직 PKI 하나로 관리하고, 보안 방식이 둘로 늘지 않는다.
- **설치 환경에 덜 묶임:** TLS는 애플리케이션 단에서 끝에서 끝까지 보호한다. 병원 내부망, 프록시, 망 구성과 상관없이 동작한다.
- **외부 의존 없음:** Tailscale은 연결 조정을 외부 회사의 서버에 맡긴다. 이를 피하려면 Headscale을 따로 운영해야 한다.
- 개인정보를 네트워크로 보낼 때 암호화하라는 요구는 TLS와 VPN 모두 만족한다. 그러므로 이 요구가 선택을 가르지는 않았다. 위의 근거들이 갈랐다.

## 검토한 대안과 버리는 이유

| 대안 | 버리는 이유 |
|---|---|
| WireGuard(Tailscale)만 쓰고 평문 HTTP | 양쪽 호스트에 에이전트를 설치하고 UDP를 허용받아야 한다. 병원 전산팀이 허락하지 않으면 쓸 수 없다. Tailscale은 외부 조정 서버에 의존한다. 키오스크 쪽 TLS와 보안 방식이 둘로 갈린다 |
| TLS + 호출자 인증서(mTLS), 토큰 없앰 | 호출자가 하나뿐이라 이득이 적고, 인증서를 하나 더 관리해야 한다 |
| TLS와 WireGuard 둘 다 필수 | 이중 방어가 되지만 운영 요건이 커진다. 필요하면 배치에서 WireGuard를 덧붙일 수 있고, 그것을 막지 않는다 |

## 결과

- 얻는 것: 망 구성과 상관없는 전송 보호, 조직 PKI 하나로 하는 인증서 관리.
- 감수하는 것: 추론 서버 인증서의 발급·갱신 부담. survey-service가 조직 CA를 신뢰하게 하는 설정이 필요하다(작업 항목). 추론 서버 앞에 Caddy를 하나 더 둔다. TLS handshake 비용과 지연은 측정하지 않았다.
- 개발 중에는 tailnet 안에서 평문 HTTP로 시험해도 된다(합성 데이터 한정). 실제 환자 데이터가 오가기 전에 TLS를 갖춘다.

## 되돌리는 조건

배치 환경이 TLS 종단(인증서 배포)을 둘 수 없고 VPN만 허용되면, WireGuard 기반 안을 새 ADR로 다시 비교한다.
