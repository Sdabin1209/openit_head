# 계약 3.0.0 후보 (깨지는 변경 모음)

- 상태: **계약 1~6은 boundary-contracts v3.0.0(8163b9c, 2026-10-30)으로 냈다.** 7(문진 스키마 2.0.0)은 survey-service가 진행. 영역 전환 진행(브리프 ~/openit-logs/u300-brief.md). 이전 상태: 모으는 중. 2.x에서 하위 호환을 지키느라 미룬 깨지는 변경을 한곳에 모은다. 3.0.0을 낼 때 이 목록을 빠짐없이 처리한다.
- 처음 작성: 2026-10-30 헤드. 항목을 미룰 때마다 여기에 한 줄 더한다(근거 링크 포함).

|---|---|---|---|
| 1 | `turn_engine_version` 표지와 `BuildImageRequest.versions.turn_engine` 제거 | turn-engine 퇴역(D109). 2.x 메시지 모양을 지키느라 표지만 남김 | D109, 계약 CHANGELOG 2.5.0 |
| 2 | I9 extract 본문을 `ExtractRequest`만 받기(옛 `ActionExtractionInput` 본문 거부), `flow`·`fields` 필수 | 2.x 호출자 호환 | D108, D115, HTTP.md I9 |
| 3 | `SetupEnvReport.environment`(test_command 포함) 필수 | 영역이 모두 내게 된 뒤 | 계약 CHANGELOG 2.6.0, OPEN_GAPS U43 |
